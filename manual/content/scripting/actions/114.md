---
type: action
id: TACTION_CREATE_AUTOSAVE
title: Create Autosave
summary: Saves the game once the current frame has finished.
caveats:
  - A campaign or skirmish game writes `AUTOSAVE1.SAV`, replacing the previous autosave. A multiplayer game writes the multiplayer save file, and writes nothing once a player has left the match.
  - A second request in the same frame shares the first.
related:
  - type: format
    id: save-games
  - type: using
    id: compatibility-and-saves
---

The save is written at the same point of the frame as a multiplayer save, after the objects marked for removal have been retired, so a save requested in the middle of a trigger never captures a half-updated scenario.
